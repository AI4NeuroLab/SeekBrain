Analyze Ahrens_2018_Neuron_Zebrafish data, to understand brain's sensorimotor transformations, first, identify cells whose neural activity closely tracks the stimulus input through the regression analysis. Perform batch analysis of stimulus regression for phototactic stimulation in the available subjects (IDs: 6, 7, 10,12 to 18; the name format is subject_ID). Use the trial-averaged stimulus trace and an exponential-decay kernel of GCaMP6 ( decay half-time = 0.4 s, peak delay = 0.08 s, duration = 8 s) to generate regressors separating right and left stimuli. Find cells whose z-scored trial-averaged activity shows high Pearson’s correlation coefficient (r > 0.5) with the left and right regressors.
Plot the anatomical location (stored in CellXYZ_norm) of left- and right-tuning cells (r > 0.5), respectively. Color assignment, use red (left) and cyan (right) colormaps, and black background. Plot both top-down (XY) and side (YZ) views, aligning them with the long side. 
Use data_full.mat, TimeSeries.h5, and FishOutline.mat for analysis and visualization, which are stored in ZEBRAFISH_PATH. See the detailed description of the datasets in the meta.json file. Save useful result in npy files in PROCESS_DATA_DIR, including the indices for identifying high-correlation cells fish by fish.
