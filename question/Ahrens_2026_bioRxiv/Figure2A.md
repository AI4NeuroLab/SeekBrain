Analyze Ahrens_2018_Neuron_Zebrafish data, to understand brain's sensorimotor transformations, first,  identify cells whose neural activity closely tracks the stimulus input through the regression analysis. Use the phototactic stimulation as a demo. Use the trial-averaged stimulus trace and an exponential-decay kernel of GCaMP6 ( decay half-time = 0.4 s, peak delay = 0.08 s, duration = 8 s) to generate regressors separating right and left stimuli. Find cells whose z-scored trial-averaged activity shows high Pearson’s correlation coefficient (r > 0.5) with the left and right regressors. Visualize the left (red) and right (cyan) regressors and the corresponding DF/F traces (mean ± SD) of these selected cells, respectively. Use data_full.mat and TimeSeries.h5 files of subject_7 for analysis, which are stored in ZEBRAFISH_PATH. See the detailed description of the datasets in the meta.json file.
