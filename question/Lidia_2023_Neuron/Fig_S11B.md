To evaluate the statistical association between the expression of two GPCR(G protein-coupled receptor) genes in the C. elegans nervous system, a bubble plot was generated showing the Fisher's exact test association for each GPCR pair. The color indicates the FDR (False Discovery Rate) corrected p-values for each GPCR pair (log scale). The size of each bubble indicates the possible binding cooperativity between the two GPCRs, from 0 to 7.
