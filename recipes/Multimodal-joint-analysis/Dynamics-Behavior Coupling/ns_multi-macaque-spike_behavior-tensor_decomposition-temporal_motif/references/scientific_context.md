# Scientific context

## Methodological requirements

*   **Task Structure:** Two-target reaching task with variable stimulus evidence (the "Random Dot Motion" equivalent for reaching).
*   **Data Analysis (Spike Density Functions):** Gaussian kernel smoothing (typically $\sigma = 20-50$ ms) to produce trial-averaged firing rates.
*   **Classification Criteria:** The use of receiver operating characteristic (ROC) analysis or peri-stimulus time histograms (PSTHs) to identify the "choice-selectivity" window.
*   **Condition Sorting:** Aligning data to target onset and sorting trials by target location (Left/Right) and coherence level.

## Required data

*   **Neuronal recordings:** Single-unit activity from the PMd of macaque monkeys.
*   **Behavioral parameters:** Choice (Left/Right) and Task Difficulty (stimulus coherence levels).
*   **Time alignment:** Data must be aligned to both stimulus onset (to see decision evolution) and movement onset (to separate decision from motor execution).

## Validation criteria

To determine if a model or study section successfully answers the question, it must:
1.  **Categorization:** Does the explanation distinguish between monotonic (ramp-like) and non-monotonic (transient/phasic) profiles?
2.  **Modulation:** Does it address whether the firing rate modulation correlates with *both* choice (direction) and difficulty (signal strength)?
3.  **Theoretical Contrast:** Does it explicitly explain how the presence of non-ramping cells contradicts the "classic" decision-making hypothesis where all neurons serve as pure evidence accumulators?
4.  **Temporal Dynamics:** Does it account for the shift in latency of activity based on stimulus difficulty (i.e., do harder trials show slower/delayed ramping)?
