# Multi-Timescale Velocity Encoding Analysis

This recipe focuses on characterizing the temporal integration properties of individual neurons by assessing how their firing rates correlate with the animal's velocity filtered over a broad spectrum of temporal decay constants ($\tau$). By applying exponentially weighted moving averages (EWMA) to behavioral velocity traces, we can identify whether a neuron is tuned to momentary bursts of speed or sustained average running pace.

The implementation relies on synchronizing spike timestamps with behavioral tracking, performing a series of causal convolutions using varying kernel widths, and calculating Pearson correlation coefficients to map the "preferred timescale" for each neuron in the recorded population.

## When to use this

Use this recipe to estimate each neuron's preferred velocity-integration timescale by correlating firing rate with exponentially filtered velocity. Do not use it without synchronized neural and behavioral timestamps or without controlling for autocorrelation-driven significance.

## Scientific context

Neurons in navigation-related circuits often exhibit diverse temporal responses. Some neurons act as integrators, sensitive to long-term velocity trends, while others act as differentiators, responding to instantaneous changes. This diversity allows the neural population to represent motion across multiple concurrent temporal windows.

## Preconditions

* `numpy`: For array manipulation and log-spacing of parameters.
* `scipy.signal`: For the `lfilter` function (causal implementation).
* `scipy.stats`: For `pearsonr` or `spearmanr` calculations.
* `matplotlib`: For visualization of correlation matrices and example traces.

## Inputs and outputs

1. `spike_times`: Array of spike timestamps per neuron.
2. `behavior_data`: DataFrame containing `time`, `x`, and `y` coordinates.
3. `bin_size`: Scalar (e.g., $0.02$ seconds).

* `timescale_matrix`: A $(N_{neurons} \times N_{\tau})$ matrix of correlation coefficients.
* `optimal_taus`: A vector of length $N_{neurons}$ containing the $\tau$ value at `argmax` of the correlation.
* `example_figures`: Time-series plots for the 3 neurons with the most distinct optimal timescales.

## Procedure

1. **Behavioral Preprocessing:** Derive instantaneous velocity $v(t)$ from high-resolution tracking coordinates $(x, y)$.
2. **Exponential Filtering:** Apply a causal EWMA filter to velocity: $V_{filt}(t) = \int_{0}^{\infty} V(t-\tau) \cdot e^{-\tau/\tau_{d}} d\tau$.
3. **Correlation Mapping:** Correlate binned firing rates with $V_{filt}$ across a log-spaced range of decay constants $\tau \in [100ms, 10s]$.
4. **Timescale Optimization:** Determine the $\tau$ that yields the maximum Pearson correlation coefficient for each neuron.

1. **Synchronization:** Align spike trains and $x, y$ coordinates to a common bin size ($dt \leq 20ms$).
2. **Kernel Generation:** Generate a vector of decay constants $\tau$ (e.g., 30 log-spaced values from $0.1$ to $10.0$ seconds).
3. **Convolution:** Use `scipy.signal.lfilter` to perform causal filtering on the velocity trace, ensuring that the filter is normalized so that the sum of the kernel coefficients equals 1.
4. **Correlation:** Compute Pearson $r$ between the binned firing rate and the filtered velocity trace for every $\tau$.
5. **Selection:** Identify the optimal $\tau$ per neuron using `np.argmax`.

1. **Calculate Velocity:** Compute $v_t = \sqrt{(x_{t+1}-x_t)^2 + (y_{t+1}-y_t)^2} / dt$.
2. **Generate Filter Bank:** Define $\tau_{range}$ as `np.logspace(np.log10(0.1), np.log10(10), 50)`.
3. **Convolve:** Loop through $\tau_{range}$, applying the causal exponential filter to $v_t$ using `lfilter`.
4. **Correlate:** For each neuron, compute a correlation vector of length 50 against the filtered velocity traces.
5. **Analyze Significance:** Compare the peak correlation against a null distribution generated by shuffling spike times 500 times.

## Expected results

The distribution of optimal decay constants ($\tau_{1/2}$) across the neuronal population will be broad, demonstrating that velocity encoding is not a uniform process. Representative examples should show distinct sensitivity peaks at varying integration windows.

* Check that $V_{filt}$ has the same units and comparable range as raw velocity.
* Confirm that filtered velocity traces become smoother as $\tau$ increases.
* Verify that `argmax` correlations are significantly higher than the median of the shuffled (null) distribution.

## Pitfalls

* **Boundary Effects:** Ensure that the initial 500ms of the velocity trace is discarded after convolution to prevent artifacts caused by filter initialization.
* **Spatial Bias:** If the animal's path is constrained, velocity-tuning might be confounded by spatial tuning. Consider implementing a partial correlation analysis if results appear spatially biased.
