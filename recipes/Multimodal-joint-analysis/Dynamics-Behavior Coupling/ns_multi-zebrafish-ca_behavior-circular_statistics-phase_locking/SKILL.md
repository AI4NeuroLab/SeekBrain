# Quantifying Scene–Bump Alignment Disruption in Cognitive Maps

This recipe provides a systematic workflow to quantify the dynamic stability of internal neural representations relative to external visual cues. By calculating the angular phase offset between a neural activity "bump" and the visual scene, this analysis determines the stability of the cognitive map across distinct behavioral epochs (pre-learning, learning, and post-learning).

The workflow relies on processing time-series neural data and visual stimulus telemetry. The primary metric is the "fraction of time in out-phase," which captures the proportion of the recording duration where the neural representation diverges significantly from the environmental input.

## When to use this

- Quantify the fraction of time that the neural bump and visual scene are out of phase in each epoch.
- Compare within-subject phase disruption across pre-learning, learning, and post-learning.
- Do not use this workflow before defining and justifying the circular out-of-phase threshold.

## Scientific context

The alignment between internal neural representations (the "bump") and external landmarks (the "scene") is a hallmark of navigation and cognitive mapping. Disruptions in this alignment—quantified as periods where the internal representation loses spatial correlation with the visual environment—serve as a proxy for the stability of the cognitive map during learning.

## Preconditions

*   `numpy`: For vectorized circular arithmetic and boolean masking.
*   `scipy.stats`: For potential use of circular mean or statistical testing functions.
*   `matplotlib.pyplot`: For generating the longitudinal line-connected scatter plot.

## Inputs and outputs

1.  `neural_bump_array`: 1D array of decoded angles (radians).
2.  `scene_position_array`: 1D array of stimulus angles (radians).
3.  `epoch_metadata`: DataFrame or Dictionary mapping time-indices to (Pre, Learn, Post).
4.  `subject_id_vector`: Array identifying which fish corresponds to each time point.

*   **Data:** A CSV or NumPy matrix of shape `[N_fish, 3]` containing the computed fractions.
*   **Plot:** A visualization where the X-axis is [Pre, Learn, Post], the Y-axis is the fraction (0-1), and grey lines connect individual fish values.

## Procedure

1.  **Circular Alignment:** Calculate the instantaneous angular distance between the visual scene and the neural bump position.
2.  **Threshold Definition:** Classify the alignment as "out-phase" if the angular difference exceeds the stability threshold (typically $\pm 90^\circ$ or $\pm \pi/2$ radians).
3.  **Fractional Aggregation:** Divide the count of "out-phase" time points by the total duration of the recording epoch.
4.  **Paired Visualization:** Aggregate the fractions per subject and link individual data points across the pre-learning, learning, and post-learning epochs to visualize consistency.

### Code Architecture
The implementation follows a modular pipeline: data ingestion (metadata and neural traces), circular arithmetic processing for angular offsets, threshold-based boolean masking, and plotting routines that utilize paired scatter-line visualization to satisfy longitudinal analysis requirements.

### Key Functions and Modules
*   `calculate_circular_diff(a, b)`: Implements the `arctan2(sin(a-b), cos(a-b))` operation to handle phase wrap-around.
*   `extract_epoch_indices()`: Slices time-series based on provided experiment metadata.
*   `compute_fractional_out_phase()`: Processes the Boolean array generated by threshold comparison.
*   `plot_alignment_trajectory()`: Iterates through unique subject IDs to render the grey connecting lines.

1.  **Data Loading:** Slice the `neural_bump_array` and `scene_position_array` into three segments defined by `epoch_metadata`.
2.  **Offset Calculation:** Compute `diff = arctan2(sin(bump - scene), cos(bump - scene))`.
3.  **Thresholding:** Generate a boolean mask `is_out = np.abs(diff) > (np.pi / 2)`.
4.  **Aggregation:** For each `fish_id` and each `epoch`, compute `fraction = sum(is_out) / count(is_out)`.
5.  **Visualization:** Plot the resulting matrix using a line-connected scatter approach: `plt.plot(epochs, fish_values, color='grey', marker='o')`.

## Expected results

Expected results show whether the out-of-phase fraction is elevated during early learning or perturbation and decreases as the cognitive map stabilizes, while retaining individual-fish trajectories.

*   **Bounds Check:** Ensure the fraction outputs remain strictly within the `[0, 1]` interval.
*   **Circular Consistency:** Verify that the "out-phase" calculation correctly handles transitions from $2\pi$ to $0$ (the wrap-around point).

## Pitfalls

*   **Threshold Sensitivity:** If results differ from the method's, check if the threshold is $\pi/2$ or $2\pi/3$.
*   **Temporal Normalization:** Ensure that recording epochs of significantly different lengths are handled; consider weighting by time or excluding fish with insufficient data points.
*   **Circular Wrap:** Never use `abs(bump - scene)` without `arctan2`, as it will produce false positives at the angular boundary.
