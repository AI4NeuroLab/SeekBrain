# Scientific context

The neural bump represents an internal orientation estimate. A concentrated distribution of wrapped bump-minus-scene angles indicates stable cue locking; the von Mises concentration parameter $\kappa$ increases as angular dispersion decreases.

Evaluate significance against a null distribution formed by circularly shifting one complete trace relative to the other. Circular shifts preserve each trace's temporal autocorrelation while disrupting their alignment. An observed $\kappa$ above the 95th percentile of 1,000 shuffled values is the decision criterion used by this recipe. Apply the criterion per animal and condition rather than only to pooled data.
