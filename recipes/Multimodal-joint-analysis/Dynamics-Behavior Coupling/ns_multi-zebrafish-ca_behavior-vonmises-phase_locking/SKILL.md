# Quantifying Neural Bump-Scene Phase Coupling via von Mises Concentration

This recipe implements the analysis required to test whether a neural "bump" (e.g., in head-direction or spatial cells) maintains a stable spatial relationship with a visual scene during external perturbations such as jumps or noise. By calculating the angular difference between the neural phase and stimulus orientation, the analysis quantifies the strength of this coupling using the concentration parameter ($\kappa$) derived from von Mises distribution fitting.

To ensure the observed coupling is not a result of random alignment, the empirical $\kappa$ values are compared against a null distribution generated via circular permutation (shuffling) of the bump phase relative to the scene trajectory. This methodology is critical for confirming whether the neural representation is truly locked to the environmental reference frame during periods of stimulus instability.

To determine if the neural bump maintains a constant, statistically significant phase offset relative to the scene orientation during jump and noise epochs by comparing observed concentration parameters ($\kappa$) against an empirically derived null (shuffle) distribution.

## When to use this

Use this recipe to test whether a neural population bump preserves a stable angular offset to a visual scene during jump or noise epochs. Do not use linear differences or independent sample permutations for circular, autocorrelated traces.

## Scientific context

The neural "bump" represents an animal’s internal estimate of orientation. To function as a reliable compass, this signal must maintain a consistent, stable offset to external visual cues. If this coupling is robust, the bump should remain locked to the scene even when the stimulus orientation is abruptly altered (jump) or subject to stochastic interference (noise).

## Preconditions

*   `numpy`: Array manipulation and circular shifting.
*   `scipy`: MLE fitting (`vonmises.fit`) and statistical distributions.
*   `matplotlib`: Plotting significance bounds.

## Inputs and outputs

1.  **Neural Trace:** Continuous time-series of bump phase (radians).
2.  **Stimulus Trace:** Continuous time-series of scene orientation (radians).
3.  **Epoch Metadata:** JSON/CSV defining `start` and `stop` frame indices for jump and noise segments.

*   **Scalar:** $\kappa_{obs}$ per fish per condition.
*   **Statistic:** 95th percentile value from the shuffle control.
*   **Plot:** A visualization displaying individual $\kappa$ values for each fish, overlaid with the median and 95th percentile of the null distribution.

## Procedure

1. **Circular Alignment:** The angular difference $\Delta \theta = (\theta_{bump} - \theta_{scene}) \pmod{2\pi}$ is computed for all time points within the epoch.
2. **Distribution Fitting:** The distribution of $\Delta \theta$ is fit to a von Mises function, where the concentration parameter $\kappa$ provides a metric of coupling (higher $\kappa$ = lower variance/tighter coupling).
3. **Null Hypothesis Generation:** A shuffle control is generated by circularly shifting the neural signal relative to the scene 1,000 times.
4. **Significance Thresholding:** The observed $\kappa$ for each fish is evaluated against the 95th percentile of the shuffled distribution to determine stability.

The implementation follows a modular design: raw neural/stimulus traces are ingested from `.h5` files, processed via circular arithmetic in `utils/circular_stats.py`, fit for $\kappa$ in the analysis script, and validated through a permutation shuffle loop.

*   `scripts.run_shuffling_analysis`: Executes the circular permutation logic to establish the null threshold.
*   `analysis.plot_kappa_over_time`: Generates publication-quality figures comparing empirical vs. shuffle-derived $\kappa$.

## Expected results

A successful analysis should show that during both jump and noise epochs, the empirical $\kappa$ values remain significantly above the 95th percentile of the shuffle, indicating that the neural system maintains a reliable, constant phase offset to the visual scene despite stimulus perturbation.

*   The code must confirm that for the majority of fish, the observed $\kappa$ exceeds the 95th percentile of the null distribution during jump/noise epochs.

## Pitfalls

*   **Circular Boundaries:** Always use `np.angle(np.exp(1j * diff))` when calculating circular differences to ensure values stay within $[-\pi, \pi]$.
*   **Shuffle Logic:** Use circular shifting (`np.roll`) rather than random shuffling to preserve the internal temporal structure (autocorrelation) of the neural signal; random shuffling will lead to artificially inflated significance levels.
*   **Sample Size:** If epoch durations are too short ($<500ms$), the MLE fit for $\kappa$ may become unstable; consider merging data across trials if individual epochs are too sparse.
