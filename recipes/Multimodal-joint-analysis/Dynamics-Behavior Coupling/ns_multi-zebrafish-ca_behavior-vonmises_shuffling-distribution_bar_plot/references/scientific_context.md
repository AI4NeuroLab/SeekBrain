# Scientific context

Ring-attractor activity can be summarized by the phase of its population bump. Stable visual anchoring produces a narrow distribution of scene-minus-bump offsets and therefore a high von Mises concentration $\kappa$. A circular-shift control tests whether this concentration requires the observed temporal alignment.

The empirical analysis is distinct from forward simulation of a ring-attractor network. Model code may clarify the interpretation of concentration and stable bump regimes, but it does not replace fitting experimental offsets or constructing the shuffle control.
