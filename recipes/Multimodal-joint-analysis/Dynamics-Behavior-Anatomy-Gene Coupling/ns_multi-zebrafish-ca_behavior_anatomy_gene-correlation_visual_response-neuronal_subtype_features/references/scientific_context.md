# Scientific context

Molecular markers define candidate neuronal populations, but functional interpretation requires linking marker identity to calcium responses, motor coupling, morphology, and anatomy. This workflow joins those measurements at the neuron level, summarizes subtype distributions, and visualizes their positions in a shared zebrafish atlas.

Preserve biological replicate identity throughout the join. Treat neurons as nested within animals for inferential statistics; pooling all cells as independent observations inflates effective sample size.
