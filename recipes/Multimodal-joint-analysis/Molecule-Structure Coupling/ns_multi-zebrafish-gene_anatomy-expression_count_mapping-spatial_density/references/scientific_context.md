# Scientific context

EASI-FISH combines volumetric imaging, cell segmentation, RNA spot detection, and deformable registration to measure gene expression in anatomical context. After assigning spots to segmented cells, gene-positive and co-expressing populations can be mapped into a common zebrafish coordinate framework.

Registration quality and a consistent positivity rule across biological replicates are prerequisites for valid spatial comparisons. The example threshold of more than three spots per cell is a starting value, not a universal biological cutoff; validate it against background and signal distributions.
